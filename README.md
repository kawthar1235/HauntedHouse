# Haunted House: Escape

A 3D stealth game set in a haunted house. The player must explore the environment, avoid static Gargoyle enemies and patrolling Ghosts, and find the exit without being detected.

## Features

- 3D player movement
- Idle and walking animations
- Cinemachine follow camera
- Static Gargoyle enemies
- Dynamic Ghost enemies with waypoint patrols
- Enemy detection system
- Win and lose conditions
- Main menu
- Background ambience and sound effects
- WebGL build published on Unity Play

## Controls

- W, A, S, D: Move
- Arrow Keys: Move

## Objective

Reach the exit of the haunted house while avoiding the enemies. If an enemy detects the player, the game ends and the level restarts.

## How to Run

1. Open the project using Unity 6.3.
2. Open the `MainMenu` scene.
3. Press the Play button.
4. Use WASD or the Arrow Keys to move.
